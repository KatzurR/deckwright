## Changes

The data was generated by the pipeline in [scripts/pipeline](../../scripts/pipeline) from the official English and German SRD 5.2.1 PDFs ([srd/](../../srd/)), with structure and keys from the Open5e API (document `srd-2024`):

- the texts were split into individual entries (spells, conditions, actions, magic items, class features, species traits, feats) and fields such as range, duration or components;
- line breaks, hyphenation and page layout were removed, paragraphs and lists were reformatted;
- class tables and sidebars were removed;
- some fields (for example how a feature is activated) were derived from the rules text;
- English and German entries were paired.

If you reuse these files, keep the attribution above and state your own changes.
